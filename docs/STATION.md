# Station data contract

The listener (`web/index.html`) and the admin console (`web/admin.html`) read one
file, `web/station/station.json`, produced by `scripts/build_station.py`. When the
station host runs (`python3 -m exposure_radio station serve`), the same document
is served live at `GET /api/station`.

## Station host API (loopback by default)

| Method | Path | Purpose |
|---|---|---|
| GET | `/api/station` | The document above |
| GET | `/api/settings` | Settings with secrets masked (`{"configured": true}`) |
| PUT | `/api/settings` | Save settings; header `X-Admin-Token` required |
| POST | `/api/queue` | `{"action": "play_next"\|"remove"\|"move", "id": "seg-07", "to": 2}`; token required |
| POST | `/api/learn` | `{"title": "..."}` queue a Learn topic; token required |
| POST | `/api/learn/suggest` | Ask Gemini (operator's key, Search-grounded) for trending topics; returns `topics`, `sources` and `search_suggestions_html`, which must be shown with the results; token required |
| POST | `/api/keys` | `{"provider": "tenable"\|"gemini", "values": {...}}`; token required; never echoed back |

Without the host (static hosting), the admin console runs in demo mode: changes
persist in `localStorage` only and secret fields are disabled with a note that
keys live on the station host, never in a browser.

## Zero Wire context

The news segment includes `zero_wire` briefings and `zero_wire_fetched`. Each briefing
has a title, status, CVEs from RSS category tags, summary, source URL, product coverage
and a boolean indicating that an assessment prompt is available at the source.
No prompt text is executed or loaded into the analyst.

An open action-card item receives `zero_wire` only on an exact local CVE match, with
`briefings`, `boundary`, `fetched` and `source`. This is public context outside the
tenant evidence ledger. Unmatched, fixed and unverified-only findings receive no
coverage assertion. The news drawer still shows every public briefing, including
reference items and incidents without CVEs. The console needs no key or toggle.
