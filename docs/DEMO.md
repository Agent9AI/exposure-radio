# Demonstration run-of-show

1. **Decision:** run `python3 -m exposure_radio demo --analyst replay`. Show the priority lead, validated rationale and copyable private action card.
2. **Evidence integrity:** run `make gate-demo`. Show the false fixed-count claim, unsupported all-clear, untouched valid control and tampered script refused before speech.
3. **Operational distinction:** show the transcript's new-exposure, expanded-visibility and missed-coverage lines. Open one citation and its exact subject, predicate and value.
4. **Listen and act:** open the listener, play the two-voice sample, expand the transcript and download the executive handoff. The generic notification preview contains no vulnerability identifiers.
5. **Quiet on unchanged evidence:** show the unchanged rerun decision `SILENT`. The preparation benchmark reports software time for the reproducible scenario.

The sample uses historical public-feed snapshots and generated tenant data, so the demonstration requires no live tenant or model credentials. A recorded model run is identified as a replay; the live model adapter is an explicit separate mode.
